# South America Risk Dashboard

## Overview
This project analyzes economic and political instability trends across South America from 2010–2024 using World Bank datasets and governance indicators.

## Indicators
- GDP Growth
- Inflation
- Unemployment
- Political Stability and Absence of Violence

## Tools
- Power BI
- Power Query
- GitHub

## Objective
Develop an intelligence-style dashboard capable of identifying regional instability patterns and economic stress trends.

## Status
Project in development.
